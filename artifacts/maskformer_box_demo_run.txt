=====================================================================

WHAT THIS ADDS
--------------
panoptic_annotate_video.py and sam2_dense_annotate_video.py both annotate at pixel level:
every pixel gets a coloured mask. This script keeps the same prompt-free mask-classification
model but reduces each predicted instance mask to its tight axis-aligned bounding box, and
draws rectangles instead of masks. Nothing is blended over the image, so the underlying
footage stays fully visible.

There is still no text prompt anywhere in the pipeline — the model reports everything in its
label space, unlike annotate_video.py which only tracks what the prompt names.


MODEL
-----
  Model      : MaskFormer (MaskFormerForInstanceSegmentation, transformers 4.44.2)
  Checkpoint : facebook/maskformer-swin-large-coco
  Local path : checkpoints/maskformer/maskformer-swin-large-coco
               (config.json + preprocessor_config.json + model.safetensors, 850 MB)
  Label space: 133 COCO-panoptic classes — ids 0..79 thing, 80..132 stuff

COCO (not Cityscapes) was chosen because the clips are ordinary street/plaza footage rather
than a driving dataset: the 80 COCO thing classes cover pedestrians and vehicles but also
the umbrellas, handbags, benches, potted plants and bicycles that fill a city centre, none
of which exist in the 19-class Cityscapes vocabulary.

Loading goes through AutoConfig / AutoImageProcessor / AutoModelForUniversalSegmentation, so
pointing --config/--checkpoint at the existing Mask2Former Cityscapes directory used by
panoptic_annotate_video.py works with no code change and no flag; the thing/stuff split is
resolved from the checkpoint's own class vocabulary, not from its filename.

The checkpoint directory is covered by the existing checkpoints/** and *.safetensors ignore
rules, so the weights are NOT committed.


WHY THE BOXES ARE MASK-DERIVED
------------------------------
MaskFormer has no box-regression head — it predicts N (mask, class) pairs. So the boxes come
from the masks: post_process_instance_segmentation(..., return_binary_maps=True) returns one
binary mask per surviving instance, and each mask is reduced to the tight rectangle enclosing
it. A box is therefore always exactly as tight as the segmentation underneath it, which is
usually tighter than a regressed box, at the cost of inheriting any mask error.

Three filters clean up what that conversion can produce:

  --min-box-area  (400 px)  drops distant specks that would otherwise pepper the frame.
  --min-fill      (0.10)    drops a detection whose mask fills less than 10% of its own box.
                            Those are fragmented masks — two unrelated blobs under one
                            instance id — whose enclosing rectangle spans mostly empty image.
  --nms-iou       (0.8)     class-wise suppression of near-duplicate boxes. The model already
                            assigns each pixel to a single instance so exact duplicates are
                            rare, but one object split across two queries still happens.

Stuff classes are dropped outright: a rectangle around "sky", "road" or "building" carries no
information, so only the 80 thing classes are boxed.

OUTPUT LOCATION
---------------
A new directory, outputs/maskformer_boxes/, holds the whole run: the three source clips, the
three annotated mp4s and a .boxes.jsonl sidecar per clip. It is untracked (outputs/** already
covers it) — see NOT COMMITTED below.

  outputs/maskformer_boxes/
    crosswalk_input.webm              8.1 MB    crosswalk_boxes.mp4             16.7 MB
    cobbled_street_input.webm        12.4 MB    cobbled_street_boxes.mp4        49.8 MB
    street_traffic_input.webm        57.4 MB    street_traffic_boxes.mp4       190.9 MB
                                               *.boxes.jsonl              0.3 / 0.8 / 2.0 MB

Box coordinates are written to the .jsonl sidecars by default (--no-json disables): one JSON
object per frame, holding class, label_id, track_id, score and box_xyxy per detection. Boxes
burned into pixels cannot be read back out, and the coordinates are the actual product of a
detector, so they are kept as data rather than only as drawing.

python maskformer_box_annotate_video.py \
    --config checkpoints/maskformer/maskformer-swin-large-coco \
    --checkpoint checkpoints/maskformer/maskformer-swin-large-coco \
    --device cuda

INPUT_VIDEO / OUTPUT_VIDEO are module globals rather than flags, matching the other scripts
in the repo, so the three clips were run by rebinding those two globals and calling main()
once per clip with the flags above.

Temporal colour/id stability: boxes are matched to the previous frame by IoU within the same
class (--iou-match-threshold, default 0.3); a match reuses the track's stable colour and
#number, otherwise a new track is minted. Measured from cobbled_street_boxes.boxes.jsonl:
"umbrella #1" (track 1) holds one unbroken 227-frame run, frames 5-231 — 9.1 s at 25 fps —
and "car #61" (track 273, the magenta hatchback) holds one unbroken 82-frame run, frames
148-229. Neither id is dropped and re-minted while the object stays visible.


NOTES / LIMITATIONS
-------------------
  * mp4 container, mp4v (MPEG-4 Part 2) codec. This OpenCV build has no H.264 encoder — the
    avc1/H264/X264 writers all fail to open — and there is no ffmpeg binary on the host. The
    files play in VLC, QuickTime and Windows Media Player but NOT in Chrome or Firefox, which
    only accept H.264/VP9 in mp4. Transcoding needs ffmpeg installed.
  * Track counts overstate distinct objects, badly so on street_traffic (1575 person tracks
    over 1997 frames). Matching only looks one frame back, so a pedestrian lost for a single
    frame behind another pedestrian is re-minted as a new track. What the overlay needs —
    stable colour between adjacent frames — is unaffected, but these are not MOT-grade
    identities. Real re-identification would need appearance features or a motion model.
  * A tail of low-count false positives survives the 0.7 score threshold: "airplane" 3,
    "microwave" 1, "book" 119 and some of "fire hydrant" 82 (dark bollards and litter bins)
    are wrong. "clock" 66 and "bird" 33 are genuine — the castle clock tower and pigeons.
    Raising --score-threshold trims the tail and also starts dropping distant pedestrians.
  * Backpacks are frequently labelled "handbag"; the two classes are close in COCO and the
    model is not consistent about which it picks.
  * Boxes inherit mask error. A vehicle seen through glass, or one whose mask leaks into its
    own shadow, produces a box slightly larger than the object. --min-fill only catches the
    gross cases where the mask is fragmented.

street_traffic result is 191 MB, past GitHub's 100 MB per-file limit, so it stays local; the
Commons URLs above make every clip re-fetchable and every run reproducible.
